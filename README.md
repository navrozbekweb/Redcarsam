# RED CAR | Samarqand — avtomobil ijarasi

2-mustaqil ish: Bootstrap 5.3 yordamida rivojlantirilgan veb tizim.

## Ishga tushirish
`index.html` faylini brauzerda oching (Bootstrap CDN orqali ulanadi — **internet kerak**).

## Fayllar
- `index.html` — sahifa (Bootstrap klasslari bilan)
- `style.css`  — kichik qo'shimcha uslublar
- `script.js`  — tooltip/popover, qidiruv, forma tekshiruvi
- `images/`, `audio/`, `video/` — media fayllar

## Baholash bandlari qayerda bajarilgan
| № | Band | Qayerda |
|---|------|---------|
| 1 | Responsive | `container/row/col-*`, kartochkalar 1/2/3 ustun (telefon/planshet/kompyuter) |
| 2 | Matn dizayni | "Biz haqimizda": `display-*`, `lead`, `mark`, `blockquote`, `text-*`, `fw-*` |
| 3 | Jadval va ro'yxat | "Narxlar" (`table-dark table-striped table-hover`), `list-group`, `list-group-numbered` |
| 4 | Formalar | "Bron formasi": `form-floating`, `input-group`, `form-select`, radio, switch, range, validation |
| 5 | Media va ikonkalar | `img-fluid`, `rounded`, `img-thumbnail`, `ratio` (video/xarita), audio, Bootstrap Icons |
| 6 | Dropdown | Menyudagi "Yana", saralash va bog'lanish uchun tugmali (split) dropdown |
| 7 | Konteynerli menyu | `navbar` + `container`, `fixed-top`, `navbar-toggler`, scrollspy |
| 8 | Tooltip/popover | Xizmat ikonkalari, yuborish tugmasi (tooltip); kartochkadagi ℹ tugma (popover) |
| 9 | Panel | `card` (header/body/footer), `accordion` (Savol-javob) |
| 10 | Slayder | `carousel` (hero) va mijozlar fikri slayderi |
| 11 | Yaxlit mavzu | Barcha bo'limlar "Samarqandda avtomobil ijarasi" mavzusiga bog'langan |

## Ekran o'lchamlari
- Telefon: < 576px
- Planshet: 768px — 991px
- Kompyuter: ≥ 992px
